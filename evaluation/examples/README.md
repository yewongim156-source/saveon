# 대상·순서·근거 예시

`examples.json`은 **모두 가상의 교육용 예시**이며 실제 영상이나 검증된 사실이 아니다. 원본 평가셋이나 성능 지표에 포함하지 않는다. 각 예시는 `gold`에 추가할 수 있는 필드만 보여준다.

- `product`: 두 제품의 추천 이유를 각 제품에 연결하고 공식 자료 확인을 요청한다.
- `place`: 장소별 특징과 최신 운영시간 확인 요청을 구분한다.
- `recipe`: 영상 전체의 조리 순서와 선택 단계를 표현한다.
- `exercise`: 하나의 운동 대상에 자세 순서와 조건을 연결한다.
- `tools`: 여러 GPT 활용 기능 각각에 별도 절차를 연결한다. 실제 제품 기능을 설명하는 예시는 아니다.

`evidence`는 영상 근거다. `externalExpectations`는 외부 검색으로 검증하거나 보완할 항목이며, `NOT_REVIEWED`와 빈 `sources`는 아직 확인하지 않았다는 뜻이다. 실제 출처를 확인한 뒤에만 `REVIEWED`와 URL·제목·확인일·근거 내용을 적는다.
