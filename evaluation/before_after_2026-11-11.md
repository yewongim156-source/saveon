## 근거 검증

검증 대상이 생성된 7개 영상은 `INSUFFICIENT_EVIDENCE`, 나머지 3개는 `NO_VERIFIABLE_CLAIMS`. 검증 대상에 대한 Google Search Grounding은 429로 실패했다. `NO_VERIFIABLE_CLAIMS`는 모든 정보가 검증됐다는 의미가 아니다. Free tier에서 Gemini 3 계열 Search Grounding API 이용 가능 여부는 공식 요금표와 프로젝트별 설정을 확인해야 한다.

## 해석과 한계

- 10개 결과에서 2건의 JSON 파싱 실패 후 fallback이 나타났던 기존 실행과 달리, 이번 실행은 10건 모두 구조화 객체가 반환됐다. 한 번의 실험이며 오류율 보장은 아니다.
- 더 촘촘한 OCR과 출력 스키마 변경을 동시에 적용해 각 변경의 개별 기여도를 분리할 수 없다.
- 각 target의 details와 steps에는 아직 근거 ID가 자동 연결되지 않아 환각 여부를 기계적으로 검증할 수 없다.
- AI 생성 건강 효과, 순위, 가격, 장소명은 사실로 확인된 것이 아니다. 검색 실패 시에도 원문 요약에 주장이 단정적으로 남을 수 있어 사용자 제공 전 안전한 처리 개선이 필요하다.
- 기존 모바일 화면은 structured.targets를 렌더링하지 않는다. 모바일 상세 화면 연동은 별도 작업이다.
- 사용자 데이터와 모델 제공자 정책·보존 설정에 주의해야 한다. OCR 텍스트는 structuredAnalysis에 포함돼 저장된다.
