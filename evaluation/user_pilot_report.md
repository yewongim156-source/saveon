# 사용자 제공 숏폼 10개 1차 분석 평가

평가일: 2026-11-11. 대상: 로컬 `codex/rag-structured-search` 브랜치. 다른 개발자의 백업 브랜치나 실제 배포 앱을 검증한 결과가 아니다. 사용자 제공 링크를 Spring API로 등록하여 저장된 결과를 확인했다. 별도 Whisper/OCR과 8개 프레임의 보조 증거를 비교했으며, 원본 전체를 사람이 검토한 골든셋은 아니므로 아래는 잠정 평가다. 가격·운영시간·효과는 외부 검증 결과로 간주하지 않는다.

## 전반 결과

- 10개 모두 애플리케이션 상태는 `COMPLETED`였다.
- 화장품·데이트 코스 2건은 Gemini 구조화 응답이 불완전한 JSON으로 파싱 실패해 대체 결과가 저장됐다.
- GPT 스킬, 복근 운동, 로제파스타, 카페, 등산 코스에서 검색 기반 사실검증이 429 할당량 오류로 실패했다.
- 10개 응답은 제품·장소·단계별 정보 카드가 아닌 문장 또는 원시 추출 결과다. 정보가 응답 어디에도 없으면 누락으로 기록하며, 카드 형식이 없는 것만으로 정보 누락이라고 판단하지 않는다.
- 앱 분석과 별도 증거 수집을 동시에 진행했으므로 소요 시간은 속도 벤치마크가 아니다.

## 1. 화장품 추천 — user-001

원본: https://www.youtube.com/shorts/waqvnBsCyHA

- 확인된 대상: 페리페라 블러셔, 유리아주 컬러 립, 코스노리 아이래쉬 틴팅 세럼, 컬러그램 누디 블러 틴트, 메이크업 픽서. 세부 제품명과 가격은 OCR 초안이므로 재확인 필요.
- 실제 출력: 원본 제목과 STT 앞부분 260자, 의미 없는 OCR 조각이 그대로 요약에 포함됐다.
- 누락: 제품별 이름·특징·가격·추천 이유가 완성된 형태로 제공되지 않는다. 뒷부분의 제품 정보가 잘렸다.
- 오류: OCR 조각이 엔티티에 섞이고 `기술` 카테고리가 붙었다. Gemini JSON 파싱 실패 후 fallback이 사용됐다.
- 사실검증: fallback에서 검증할 주장이 생성되지 않았으며, 표시된 가격은 현재가로 검증되지 않았다.
